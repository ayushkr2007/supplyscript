# SupplyPrescript Dashboard

React + Vite frontend for the SupplyPrescript decision board.

## Setup

```
npm install
```

## Data

This app reads `public/prescriptions.json`. Generate it by running the
optimizer from the main project repo:

```
python src/w2_day3_json_output.py
```

Then copy `data/prescriptions.json` into `public/prescriptions.json` here.

## Run

```
npm run dev
```
